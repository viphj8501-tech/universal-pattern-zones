### v2.0 — 수명주기 집계·필터 차단 사유
- 저장된 패턴·캔들 목표 박스의 후보/확인/목표 도달/무효화 수량 표시

- 현재 상승·하락 설정에서 품질 필터를 통과하지 못하는 이유를 거래량/ATR/세션/HTF 추세별로 표시

### v1.0 — 오더 블록·FVG 컨플루언스
- 같은 방향의 활성 오더 블록과 미완전 해소 FVG 가격 범위가 겹치면 컨플루언스 박스를 생성
- 소스 생성 봉 키를 사용해 동일 OB/FVG 조합의 중복 표시 방지
- OB 무효화·제거 또는 FVG 완전 해소 시 파생 컨플루언스 영역을 종료
- 상승 컨플루언스 주변의 EQL, 하락 컨플루언스 주변의 EQH가 근접하면 라벨에 추가 정보
- 탐지 켜기/끄기, 근접 허용 ATR 폭, 박스 수 상한 및 개별 알림
- 근접 EQH/EQL은 문맥 정보일 뿐, 내부/외부 유동성의 완전한 분류나 매매 신호가 아님

### v1.1 — 하모닉 패턴 확장 및 알림 코드 제거
- 사이퍼: B점 AB/XA 되돌림, C점 BC/XA 확장, D점 CD/XC 되돌림의 조합 검사
- 샤크: B점의 XA 바깥 확장, BC/AB 확장, D점과 X점 사이의 상대 거리 검사
- AB=CD 1.272 / 1.618 확장 변형을 분리 표시
- 각 새 하모닉 계열의 켜기/끄기 설정
- alertcondition() 및 alert() 호출 전부 제거; 패턴 모듈 완성 후 알림 모듈을 별도로 추가
- 비율 조건과 피벗 순서가 각 시장·시간대에서 적절한지 TradingView에서 검증 필요

### v1.2 — 추가 캔들 패턴
- 도지: 전체 범위 대비 몸통 비율을 기준으로 식별하고, 방향은 확정 신호로 간주하지 않음
- 상승·하락 하라미: 작은 현재 몸통이 이전 반대색 몸통 안에 있는지 검사
- 관통형·먹구름형: 이전 몸통의 중간값을 현재 종가가 회복·이탈하는지 검사
- 집게형 고점·저점: 두 캔들의 극값 차이를 ATR 및 최소 틱 허용 오차로 비교
- 인사이드·아웃사이드 바와 ATR 크기 및 몸통 비중을 이용한 장대양봉·장대음봉
- 기존 목표 영역·무효화·오브젝트 개수 제한과 연결
- 알림 호출은 없으며 패턴 전체 구성이 끝난 후 별도 모듈로 계획

### v1.3 — 차트 패턴 확장
- 라운딩 바텀 / 라운딩 탑: 7개 확정 피벗에서 테두리·중앙 극값·양쪽 곡선 진행을 근사 검사
- 컵앤핸들: 비슷한 좌·우 테두리, 충분한 컵 깊이, 얕은 손잡이 조정의 4개 피벗 구조
- 확장형 천장 / 확장형 바닥: 고점과 저점이 연속으로 확장되는 5개 피벗 구조
- 다이아몬드 천장 / 다이아몬드 바닥: 9개 피벗에서 넓어졌다가 좁아지는 스윙 구조
- 최소 높이, 테두리 허용 오차, 확장 폭 및 패턴군별 탐지 on/off 설정
- 공통 패턴 라이프사이클의 넥라인 확인·목표·무효화와 연계
- 모든 패턴이 완성될 때까지 알림 호출은 포함하지 않음

### v1.4 — 내부·외부 유동성 및 HTF 컨플루언스
- 선택한 상위 시간대의 이전 확정 롤링 고가·저가 범위를 `request.security()`로 읽음
- 이전 확정 HTF 봉 참조 `[1]`과 `barmerge.lookahead_on`을 사용해 미확정 HTF 봉 값 사용을 피함
- EQH/EQL을 HTF 상·하단 경계 폭과 비교해 내부 유동성 / 외부 유동성 / 범위 외부로 분류
- EQH/EQL 라벨에 HTF 상단·하단 근접 맥락을 표시
- OB+FVG 컨플루언스가 HTF 범위 상단·하단에 가까우면 위치 태그를 추가
- 상위 시간대, 범위 길이, 경계 허용 폭을 입력으로 제공; 차트 시간대가 같거나 높으면 HTF 분류를 적용하지 않음
- 분류는 HTF 롤링 범위 기반 프록시이며, 모든 ICT 유동성 프레임워크의 완전한 구현은 아님
- 패턴 개발이 끝날 때까지 알림 호출 없음

### v1.5 — 거래량·ATR·HTF 추세·세션 품질 필터
- 거래량 평균 기간과 평균 대비 최소 배수에 따라 신규 영역·핵심 신호를 필터링
- ATR/종가 퍼센트 최소값으로 낮은 변동성 구간의 신규 신호를 선택적으로 억제
- 이전 확정 상위 시간대 종가와 EMA를 비교해 방향별 패턴을 필터링; 상위 시간대 요청에 [1]과 barmerge.lookahead_on을 적용
- 사용자 세션·시간대 설정을 이용해 세션 밖 신규 패턴 영역을 억제
- 필터를 각각 독립적으로 설정하고 기본값은 꺼짐으로 두어 이전 버전 동작을 유지
- 알림 호출은 포함하지 않음

## 코어 원칙
- 패턴 범위와 표시 로직을 먼저 완성하고 알림은 별도 후속 단계로 추가한다.
- 한 봉에서 여러 캔들 패턴 조건이 겹치면 더 구체적인 반전 패턴을 우선 표시한다.
- 패턴 탐지, 목표 영역 산출, 박스 상태 관리를 분리한다.
- 후보 상태와 확정 상태를 구분하고 종가 확정을 우선한다.
- 피벗 확인 지연과 과거 차트의 표시 특성을 문서화한다.
- 각 패턴의 감지 조건, 무효화 규칙, 목표 가격 공식을 명시한다.
- 박스 수 제한, 오래된 객체 정리, 단순 기울기 외삽의 한계를 관리한다.
- 표기된 목표 영역은 기술적 추정이며 매매 성공이나 수익을 보장하지 않는다.

### v1.6 — 일반 가격 갭 및 해소 상태 추적
- 연속한 두 봉의 가격 범위가 겹치지 않는 상승·하락 갭을 탐지
- 최소 갭 크기를 ATR 배수로 설정하고 v1.5의 공통 품질 필터를 적용
- 갭 박스를 미충전 / 부분 해소 / 완전 해소 상태로 관리
- 박스 수 상한을 두고 오래된 영역은 객체 배열에서 함께 제거
- 3개 봉 기준 FVG와 별도의 클래식 가격 갭 모듈로 유지
- 알림 호출은 포함하지 않음

10. 배열 최대 개수 제한을 넘겨 오래된 객체가 제거될 때 통계도 함께 반영되는지 확인
