# 통합 패턴 영역 — 모듈 확장 및 검증 로드맵

## 현재 구현 상태

### v0.1 — 클래식 반전 패턴
- 이중천장 / 이중바닥
- 헤드앤숄더 / 역헤드앤숄더
- 후보 / 완성 확인 / 목표 도달 / 무효화 상태 박스

### v0.2 — 가격 불균형(FVG)
- 상승 / 하락 FVG
- 부분 해소 / 완전 해소 상태 및 알림

### v0.3 — 캔들 패턴
- 상승 / 하락 장악형
- 상승 / 하락 핀바
- ATR 기반 목표 영역 및 신호 캔들 극값 무효화

### v0.4 — 삼각형·쐐기
- 상승 삼각형 / 하락 삼각형 / 대칭 삼각형
- 상승 쐐기형 / 하락 쐐기형
- 종가 기준 경계 돌파, 패턴 높이 측정 목표 영역

### v0.5 — 한글화 및 추세 지속 패턴
- 기존 차트 패턴명, 박스 상태명, 피벗명, 알림 제목을 한글로 통일
- 상승 / 하락 깃발 및 페넌트
- 직사각형 박스권 / 상승·하락 채널
- 돌파선 재시험 대기 / 성공 / 실패 / 시간 만료 상태와 알림
- 수평 박스권으로 판정된 패턴은 위·아래 경계를 수평으로 유지

### v0.6 — ICT/SMC 기본 구조
- BOS: 종가 기준 최근 확정 스윙 고점·저점 돌파
- CHOCH: 추적 중인 구조 방향에 반대되는 종가 돌파
- 고점·저점 유동성 스윕: 꼬리가 스윙 레벨을 넘고 종가는 레벨 안쪽에서 마감
- 오더 블록: BOS/CHOCH 직전 최근 반대 방향 캔들의 전체 고가~저가
- 오더 블록 재방문 및 종가 기준 무효화 상태
- 한글 박스 라벨과 개별 알림 조건

### v0.7 — EQH/EQL 및 오더 블록 정교화
- Equal Highs / Equal Lows를 상·하단 유동성 풀로 탐지
- 비슷한 가격대의 활성 풀은 병합해 중복 박스 수를 억제
- 유동성 풀 스윕을 한 번만 표시하고 스윕 완료 박스로 상태 변경
- 오더 블록 영역을 전체 캔들 범위와 몸통 범위 중 선택
- EQH/EQL 감지 및 스윕 방향별 알림 추가
- 동일 높이 허용 오차는 ATR 배수와 최소 틱 크기로 산출
- 여전히 단순화된 구조 근사이며, 내부·외부 유동성이나 상위 시간대 컨플루언스는 향후 고도화 대상

3. 내부·외부 유동성 구분, Equal High/Low 주변 컨플루언스, OB/FVG 연계
4. 고급 구조: 브레이크아웃/리테스트 독립 탐지, 채널 회귀, 다중 시간대 정렬
5. 품질 필터: 거래량, ATR, 상위 시간프레임 추세, 거래 세션

## 코어 원칙
- 패턴 탐지, 목표 영역 산출, 박스 상태 관리를 분리한다.
- 후보 상태와 확정 상태를 구분하고 종가 확정을 우선한다.
- 피벗 확인 지연과 과거 차트의 표시 특성을 문서화한다.
- 각 패턴의 감지 조건, 무효화 규칙, 목표 가격 공식을 명시한다.
- 박스 수 제한, 오래된 객체 정리, 단순 기울기 외삽의 한계를 관리한다.
- 표기된 목표 영역은 기술적 추정이며 매매 성공이나 수익을 보장하지 않는다.
